## Maximal-Free Playbook

1. **Daily coding** → free models in Cline / Freebuff, or OpenCode + free keys (Google AI Studio, Token Harbor `:free`, OpenRouter `:free`, Groq). → [FREE-ACCESS.md](./FREE-ACCESS.md)
2. **Need a frontier model** → Claude.ai free (Sonnet 5), Kimi K3 free on kimi.com, or burn cloud credit: Bedrock/Vertex for Claude Opus 5.5.
3. **Student?** → GitHub Student Pack (Copilot Student) + Google AI Pro/Plus free year + ChatGPT Plus 4 months (US) + Codex $100.
4. **Building a startup?** → Google (up to $350K) · AWS Activate (up to $200K) · Microsoft (up to $150K).
5. **Own a Copilot/Claude sub?** → CLIProxyAPI to reuse it as an API (account risk).
6. **Need a GPU?** → Kaggle 30 h/week + Colab + Modal $30/mo + AMD $100.

> **Privacy:** free tiers are often paid for with your prompts. Keep customer data and secrets on paid, no-training tiers.

## Part 6 — Provider Trust Status

> Rule: a provider gets a plain entry only when it is confirmed real and doing what it claims. A real product with a rough edge gets one caveat sentence. Anything unconfirmed stays in the "not stable" list. Domains below were re-checked (HTTP) on 29 Sep 2026.

### Clean — confirmed real, does what it says

Arena.ai, Genspark (free 100 credits/day), Hix.ai, Deepgram, Ninjachat.ai, OmniRoute, Zenmux.ai, Studentoffers.co, DeepSeek Harness, Blaxel, E2B, Modal, Vercel, Northflank, Dokie.ai, Mwm.ai, Architecto.dev, Framer, Relevance AI, Manus (free 300 credits/day), Pomelli (Google Labs), Opal (Google), Token Harbor, Freebuff, Cline.

### Use with a caveat — real, but read the note

| Provider | Caveat |
|---|---|
| **Relume** | Not a standalone site builder — outputs sitemaps/wireframes into Webflow or Figma |
| **Runable** | Free 1,500 credits/day; paid plans are $2,000+/mo and its performance numbers are vendor marketing |
| **Draftly.space** | Real 3D scroll-site builder; don't confuse with draftly.live or draftly.so |
| **Magnific** | Live (blocks automated checks); pricing not re-read this pass |
| **Resourify.com** | Deals directory (Standard $20/mo); spelled without a "c" |
| **CodeSandbox** | Now owned by Together AI; Build plan $0, Scale $170/mo |
| **Daytona** | "Sub-90 ms boot" is a vendor claim, not measured here |
| **TokenRouter** | Real 300+ model gateway; paid models at list price, some `:free` IDs with limited capacity — not a guaranteed free tier |
| **Cto.new** | Real company; its "free unlimited" is a promotion, not a standing tier |
| **Moda.app** | Site is live; features not re-tested. Not the same as modaai.app |

### Unverified — not a confirmed free tier, use at your own risk

- **AgentRouter** · **Bluesminds** — see flagged rows in [FREE-ACCESS.md](./FREE-ACCESS.md); GitHub account 1+ year old required; credit amounts keep shrinking
- **api.hcnsec.cn** and other check-in credit routers

> **Never a source of a plain fact:** perkstack, choosfy, buldrr, costgoat, tokenmix, pricepertoken, aitoolsradar, bestaiforstudents, apidog, serenitiesai, aimadetools and similar SEO aggregators.

### Kept out entirely

- **Lumosel.vip** — scam. "Opus/Sonnet" requests answered by DeepSeek, fake token counter, self-described Chinese grey-market proxy.
- **Aerolink.lat** — "Opus/Sonnet" requests answered by Qwen, fake token counter, grey-market proxy; bans multi-account devices and keeps balances.
- **Oxaam.com** — pooled/shared-login "free subscriptions" farm, flagged as a scam on r/Scams, r/isthisascam and r/AI_Agents. Never enter a real login.
- **ZCode** — silently uploaded users' repositories (see [NEWS.md](./NEWS.md)).
- **TokenLB.net** · **CatAPI** — domains no longer resolve (29 Sep 2026).
- **Chinese credit routers in general** (TabiToken, Tokeness, GoRouter, TokenLayer, yunwu, AiWave…) — assume model substitution until you've tested them; see the check in [FREE-ACCESS.md](./FREE-ACCESS.md#chinese-credit-routers-community-reported--unverified).
- **Verdant.ai** — name shared by four unrelated companies; left out until disambiguated.
